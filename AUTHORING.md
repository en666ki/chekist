Этот файл — чтобы продолжить работу с холодного старта: как устроена игра, как придумываются дела, что уже заложено под следующие акты и как вносить правки, ничего не сломав.

Соседние документы:

- `DESIGN.md` — замысел, механики, план актов II–IV, концовки.

- Этот файл — рецепты, справочник по данным, мир и процесс.

Состояние на 10.XI.2026, после сдачи акта II.

## 2. Что просил заказчик

Это рамка, её нельзя потерять при любых правках.

- Геймплей, а не визуальная новелла: дела с лицами, бумаги, сверка строк между документами.
- Дискомфорт передаётся механикой и нарративом, **не внутренним монологом героя**. Игра не комментирует — она не даёт подписать, пока не вычеркнешь.
- Последствия должны ощущаться: газета, картотека, люди, которые возвращаются или исчезают.
- Счётчик доверия. Явно антисоветские поступки — быстрый конец игры. Отказ в финале акта ≈ конец игры.
- Арка: Ягода (рутина, дела всё страннее, вынужденное решение) → облегчение при смене на Ежова → чистка старых кадров (и негодяев, и симпатичных) → террор с планами и скрытым учётом нарушений → Берия: ревизия старых дел по поведению игрока плюс текущие дела.
- 3–5 часов, реиграбельность, разные концовки, потом секретные пути.
- Выглядеть должно «относительно богатенько».
- Графику прежних игр и чатов за референс не брать. Из фабулы разрешена только третья часть `survive-the-revolution` (github.com/en666ki).
- В тексте игры нет ни мата, ни разговорного тона автора: только язык эпохи.
- Гайд в начале — без подноготной: только то, что игрок видит на столе.
- Режим отладки должен показывать заранее, что куда ведёт.

## 4. Движок за пять минут

Фазы (`S.phase`): `guide` → `brief` → `desk` → `evening` → (следующий день: `brief`) … → `inter` → `end`. Маршрутизация — `go()`.

Состояние (`newState`): `name, day, phase, step, trust, viol, blind, cover, stretch, flags[], time, cases{}, cards[], cur, ending`. По каждому делу (`rt(id)`): `found[], struck[], att[], unlocked[], fresh[], hits[], verdict, refused, pos{}`, после подписи ещё `founded` и `stretch`. Версия сохранения `v: 2`; новые поля нормализуются в `load()`, версию без нужды не менять.

Сверка (`pick`): две строки → ищется пара в `cs.pairs`.

| Исход | Цена | Что говорит игра |
| --- | --- | --- |
| Пара есть, факт новый | 15 мин | «В пользу обвиняемого» или «Уличает» + текст факта |
| Пара есть, факт уже в справке | 0 | «Уже записано» |
| Обе строки из одного ненайденного факта, но пары между ними нет | 15 мин | «Об одном, сверьте каждую с третьей бумагой» |
| Одна из строк ещё участвует в ненайденной паре | 15 мин | «Вывода не сделать, одна ещё пригодится» |
| Мимо | 30 мин | «Ни расхождений, ни связи» |

День — `minutes: 540` (9:00–18:00). После шести сверять и запрашивать нельзя, подшивать и подписывать можно. Запрос недоступен, если после него не останется 15 минут.

Подпись (`sign`), по порядку:

1. `refuse: true` — первый раз возврат с резолюцией и −1 доверия (не ниже 1), второй раз концовка `e_refuse`.
2. Обоснованность: сумма весов подшитых и невычеркнутых фактов из `grounds` ≥ `need` (по умолчанию 2). Решение без `grounds` обосновано всегда.
3. Эффект: `fx`, поверх него `unf`, если не обосновано. Доверие зажимается в 0–10.
4. Скрытые счётчики: каждый вычеркнутый факт `ex` → `viol++`, вычеркнутый `in` → `cover++`; среди `conflicts` есть ненайденный `ex` → `blind++`; натяжка → `stretch++`.
5. Флаги решения — в `S.flags`. Карточка — в `S.cards`.
6. Штамп падает на анкету, через 850 мс открывается постановление с резолюцией. Доверие 0 → после «Сдать папку» концовка `e_fired`.

Натяжка (`isStretch`): все `grounds` решения уличающие, решение обосновано, и все подшитые по делу основания — косвенные (`w: 1`).

Подшить можно не больше трёх фактов (`MAXATT`). Подписать, пока в справке есть невычеркнутый факт из `conflicts`, нельзя.

Памятка (`dirDoc`) — отдельная бумага на столе: директивы всех прошедших дней плюс сегодняшние, сегодняшние помечены. Ключи строк — `dir.<id>`, с ними тоже сверяют.

Место службы и начальник берутся из дня (в акте II — общий объект `OBL` в `act2.js`): `act`, `org`, `office`, `unit`, `boss`, `bossTitle`, `fired` (концовка при нулевом доверии), `warn` (записка при доверии 1–2), `ps` (приписка в резолюции). Без этих полей работают значения первого акта. Шапка газеты — `paper.mast`. «Памятка» показывает директивы только своего акта (`act`).

Между актами: у последнего дня акта поле `inter`. Вечер → газета интермедии → сцена → архивная карточка → `nextact`. Если у интермедии есть `ending`, вместо карточки идёт концовка (так кончается последний готовый акт). Сохранение, остановившееся на концовке `act1`, продолжается кнопкой «Акт второй».

### Вид

- Стол — только фототекстуры (`assets/tex`) и свет; ничего нарисованного поверх. Пользователь отверг векторные предметы как «мультяшные» и интерфейсные панели как «CRM».
- Всё, с чем игрок работает, — бумага: бланк, лист, отрывной листок. Не кнопки, не переключатели, не рамки.
- Портрет — условное лицо, испорченное фильтрами `#pphoto`, `#pblot`, `#pgrain` из `index.html`. Приметы лица — поля `face`: `gaunt`, `scar`, `bruise`, `squint`, `jowl`, `stub`. Второй аргумент `portraitSVG` — номер дела на дощечке.
- У дня в акте II есть поля бланка: `bossPost`, `city`, `seal`.
- Дню можно задать `start: s => [строки]` — последствия, которые случаются до того, как игрок сел за стол (может менять `s.trust` и `s.time`). У дела — `epilog: [{ if, t }]`, строки в картотеку.

## 5. Формат данных

### Дело (`CASES.<id>`)

| Поле | Смысл |
| --- | --- |
| `no`, `title`, `charge` | Номер, название папки, обвинение на обложке |
| `note` | Записка Черных, пока папка открыта (необязательно; иначе записка дня) |
| `finale` | Красная папка |
| `person` | `name` и `face` (`s`: m/f, `age`, `hair`, `beard`, `must`, `hat`, `glasses`, `gray`, `seed`, `w`) |
| `docs[]` | Бумаги |
| `requests[]` | `id, label, hint, cost, doc` — открывает бумагу с `locked: true` |
| `pairs[]` | `{a, b, f}` — пара строк и факт |
| `findings{}` | `kind`: `ex` (в пользу) или `in` (уличает); `w: 1` — косвенная, иначе вес 2; `t` — текст |
| `verdicts[]` | Решения, см. ниже |

Бумага: `id`, `kind` (`form` — бланк, `hand` — от руки, `typed` — машинопись, `resol` — резолюция на обложке), `title`, `sub`, `org`, `face: true` (ровно одна — анкета с фото, на неё падает штамп), `locked`. Строки — `L(id, подпись, текст)`; ключ строки `<doc>.<line>`. Текст может быть функцией от состояния (так выписка в финале зависит от исхода дела Дёмина); `{name}` заменяется фамилией игрока.

Решение: `id`, `label` (полный текст), `short` (для картотеки), `stamp`, `conflicts[]`, `grounds[]`, `need`, `fx {trust, viol}`, `flags[]`, `reply` (резолюция), `unf {trust, viol, reply}`, `fate` (строка в картотеку), `refuse` и `refuseText`.

### День (`DAYS[]`)

`id, date, kicker, title, minutes, rank, place, brief[], directives[{id, t}], note, cases[], paper`.

Газета: `no, date, items[], letters[]`. Заметка: `h`, `t`, `big` (передовица), `by` (подпись), `if: s => …` (условие), `c` (id дела — даёт карандашную пометку «✓ № …», если игрок это дело подписал). Письмо: `hand`, `t`, `foot`.

`INTER` — газета и сцена между актами. `ENDINGS` — `kicker, title, text[]`.

### Правило пар

Записано и в шапке `data.js`. Если две строки сами по себе устанавливают факт — расходятся или подтверждают друг друга — пара **обязана** быть. Если две строки об одном, но это слово против слова и нужна третья бумага — пары между ними нет, движок сам скажет «сверьте с третьей». Тройных связок нет, сверка только попарная.

Проверка: игрок в отладке видит на строках метку факта и ждёт, что любые две строки с одной меткой сойдутся. Каждую такую пару надо либо записать, либо убедиться, что это честное «слово против слова».

## 6. Как придумывается дело

Порядок, которым сделаны все десять.

**1. Рычаг эпохи.** У дня есть дата и настоящий документ этой даты: закон от 7.VIII.1932 и его смягчение 27.III.1933, инструкция 8.V.1933 о санкции прокурора, постановление 1.XII.1934, закрытое письмо 29.VII.1936. Документ идёт в «Памятку» и сам становится строкой для сверки. Реквизиты проверять, выдумывать нельзя.

**2. Что было на самом деле.** Сначала правда, потом бумаги. Типы, которые уже использованы:

| Тип | Дела | На чём держится |
| --- | --- | --- |
| Бытовое, раздутое до статьи | `kolos`, `telka`, `seld` | Цифра или справка сдувает обвинение |
| Настоящий враг | `yama`, `zuev` | Улики сходятся; честному игроку здесь платят доверием |
| Начальник валит на подчинённого | `demin`, `padezh` | Нейтральная ведомость против докладной |
| Донос из личного мотива | `chast`, `ochered` | Справка о выговоре или жалобе на заявителя |
| Сфабрикованное к сроку | `selkor` | Оправдания находятся все, подписать можно только вычеркнув |

Настоящие враги нужны, чтобы работа казалась работой. Без них игрок с первого дела понимает, что все невиновны, и сверка теряет смысл.

**3. Кто писал бумаги и чего хотел.** У каждой бумаги автор со своим интересом и своим почерком:

- заявление или докладная (от руки, с мотивом — он же потом один из фактов);
- объяснение или протокол допроса обвиняемого;
- казённая бумага с цифрой или датой — справка сельсовета, акт взвешивания, ведомость, накладная. Это якорь: её не оспаривают;
- анкета с лицом — соцположение, семья, дата и основание ареста;
- иногда свидетель, иногда бумага, которой нет в папке (запрос).

Четыре–семь бумаг, по три–пять строк. Одна строка — одно утверждение, иначе непонятно, что с чем сверено.

**4. Факты.** Три–пять на дело, в финале восемь.

- Два–три оправдания с весом 2.
- Одна–две хлипкие улики с весом 1: «сам признаёт, что собирала», «отвечал за склад», «церковный староста», «учился в Ленинграде». Из них шьётся обвинение — теми же руками, и это даёт натяжку.
- У настоящего врага наоборот: улики прямые, оправданий нет.
- Очевидное подтверждение («туг на ухо» в протоколе и «тугоухость» в справке) должно давать факт, пусть слабый. Иначе игра врёт, что связи нет.

К каждому факту — минимум два пути. Строки-заполнители (подписи, даты рождения) нужны как шум для холодного промаха.

**5. Решения.** Обычно три: чего хочет начальник, компромисс, прекращение.

| Решение | `conflicts` | `grounds` и `need` | `fx.trust` | `unf.trust` |
| --- | --- | --- | --- | --- |
| Жёсткая статья по невиновному | все оправдания | слабые улики, `need: 1` | +1, по «террору» +2 | на 1 ниже |
| Компромисс | часть оправданий или ничего | всё найденное или без оснований | 0 | −1 |
| Прекращение | — | оправдания, `need` 2–3 | 0…−2 | ещё на 1–2 ниже |
| Жёсткая по настоящему врагу | — | прямые улики | +1…+2 | на 1 ниже |
| Отпустить настоящего врага | все улики | — | −3…−4 | — |

`fx.viol` ставится, когда сама статья шире доказанного (58-14 без умысла, 58-8 за фразу в очереди) — нарушение есть, даже если игрок ничего не вычёркивал.

Порог должен набираться в три строки. Это проверяет `PT.check()`.

**6. Голос начальника.** На каждое решение — резолюция Ломова и отдельная на необоснованное. Он короток, циничен, говорит «запомню», объясняет цену решения через план и область, никогда не морализирует. Прекращение по чистой справке он подписывает, но напоминает, что спросят.

**7. Исход.** Строка `fate` в картотеку: сухо, с датой и сроком. «Нарсуд, 29.VIII.1934: 10 лет. Дети переданы в детдом». Исход виден только вечером.

**8. Газета.** На каждое решение — своя заметка в тот же вечер, с полем `c`. Тяжёлые исходы дают отголосок через флаг день-два спустя: дети Рябининой в сводке детдома, семья Ермакова исключена из колхоза, отпущенный поджигатель жжёт ток. Газета торжествует или молчит; о том, что на самом деле случилось, игрок догадывается сам. Передовица — по настоящей дате.

**9. Сквозные люди.** В каждое новое дело вставить хотя бы одного знакомого: понятым, подписью под справкой, строкой в заявлении. Список — в разделе 7. Главный приём акта: подпись «Селькор П. Лебедев» под заметкой три вечера подряд, на четвёртый он обвиняемый, а колонки нет.

**10. Запрос и записка.** Запрос — одна закрытая бумага за 45–75 минут с подсказкой, зачем она. Записка Черных — на «ты», коротко, подсказывает ход, а не ответ.

**11. Время.** Сосчитать: сверки на все факты × 15 минут плюс запросы. В полном дне честный игрок должен тратить 60–80 % времени, чтобы наугад тыкать было дорого. В прологе времени с запасом — это известный недостаток.

**12. Проверка.** `PT.check()`; вписать решения нового дела в карты `HARSH`, `KIND`, `FAIR`, `MID` в `tools/playtest.js`; `PT.all()`; пройти дело мышью.

### Приёмы третьего акта

- **Конвейер.** Сорок справок по пять строк: на каждую — сорок минут проверки или ни одной. Игрок сам решает, кого читать.
- **Подпись чужой рукой.** Не успел — Пескарёв отметит за тебя, подпись под списком всё равно твоя.
- **Совесть стоит вечеров.** Проверять — значит задерживаться; задерживаться — значит терять дом.
- **Свой в списке.** Тесть в справке; отвод по форме спасает подпись, но не человека.
- **Спасённые возвращаются.** По приказу «бывшие» — это те, кого ты отпустил; в их приложении — твоё постановление.
- **Дата под подписью.** Одна цифра в последнем бланке решает судьбу всего списка.

### Приёмы второго акта

Их стоит повторять и развивать в актах III–IV.

- **Твоя же бумага в чужой папке.** Выписка из старого дела с исходом, который зависит от прошлого решения игрока, и строкой «постановление вынес {name}». Уличает другого — и называет тебя.
- **Тот же приём против негодяя.** Справка на Ломова собрана так же, как дело учителя: событие в день, когда его не было, и ночной протокол. Игра этого не говорит; игрок узнаёт сам.
- **Честная статья стоит дороже лживой.** Обосновать честную квалификацию можно только фактом, который бьёт по самому игроку или по сильному сослуживцу.
- **Запрос, который нельзя сделать.** Закрыт с причиной: «этапирована, постановление вынес {name}». Последствие через два месяца игрового времени.
- **Запрос-подпись.** Бумагу приносят не из архива — её подписывает игрок. После этого она лежит в деле и её можно только вычеркнуть.
- **Вещи из первого акта как улики.** Записки наставника, которые помогали играть, изъяты и подшиты.
- **Доверие как валюта.** Спасение стоит доверия; доверие зарабатывается жёсткими статьями.
- **Записки от того, кто фабрикует.** Пескарёв каждый день советует не запрашивать именно ту бумагу, которая оправдывает.

## 8. Баланс

Доверие 0–10, старт 5, ноль — увольнение. Целевая форма, которую надо сохранять при любых правках (текущие цифры — в таблице `PLAYTEST.md`):

- **Ленивый каратель** (не читать, всем максимум) выживает и медленно растёт. Расплата — скрытый счётчик «вслепую».
- **Ленивый добряк** (не читать, всех отпускать) уволен в первый же день.
- **Честный** подходит к финалу с доверием около 3: ему тесно, но он доходит. Зарабатывает только на настоящих врагах.
- **Знающий каратель** (всё нашёл и вычеркнул) получает максимум доверия и самый большой долг в архиве.
- **Мягкий** (честный, но пожалел настоящего врага) не доживает до финала.

Акт II. Доверие переходит из первого акта. Жёсткие статьи дают +1…+2, честная статья Ломову −1, спасение ветфельдшера −1, спасение Черных −3. Форма, которую надо сохранять: честный во всём приходит к последней папке с 3 и спасти Черных не может; может тот, кто расстрелял Сычёва и Ломова по «организации».

Парадокс, на котором держится реиграбельность: кто не сверял, тому нечего вычёркивать. Незнание дешевле знания сейчас и дороже при ревизии.

## 10. Как вносить правки

1. Мелкое — правкой на месте. Массовое по данным — питоновский скрипт с проверкой единственности каждой замены.
